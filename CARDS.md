# Два независимых запроса
Карточка EARLY: служба должна начинать работу в 08:30, время окончания пока остаётся 17:00.
Карточка LATE: служба должна заканчивать работу в 18:00, время начала пока остаётся 09:00.
Общее решение после согласования: работа с 08:30 до 18:00. Оба запроса действуют одновременно.
Инцидент для третьей пары: по ошибке опубликовано response_minutes=0. Требуется вернуть 60 минут новым отменяющим коммитом и сохранить историю.
